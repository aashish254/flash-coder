# Code of Conduct

A short one, written for this project rather than adopted from a template — if
you want the full Contributor Covenant text for your own repo, it's at
[contributor-covenant.org/version/2/1](https://www.contributor-covenant.org/version/2/1/code-of-conduct/),
and I'm open to switching to it verbatim.

## Expected

- **Argue with the claim, not the person.** "This number is from a session that
  isn't in the tree" is welcome; "this is wrong" with no alternative isn't
  useful to anyone.
- **Assume good faith about competence.** People here are volunteering evenings.
  A patch that doesn't run is a normal Tuesday, not a character flaw.
- **Say what you measured and what you assumed.** Labeling a number *measured*,
  *projected* or *gated* is the difference between a helpful report and a
  misleading one.
- **Give credit where the idea came from**, including in commit messages, and
  don't pick up an issue someone else is already deep into — say what you're
  working on first.
- **Be patient with someone's first pull request**, and with a machine that
  overheats.

## Not acceptable

- Harassment, slurs, sexual attention, or any of the usual list — in issues, PRs,
  discussions, or DMs that start from this project.
- Publishing someone else's private code, traces, prompts or model weights. A
  `--trace-full` session file can contain a stranger's repository; posting one is
  a conduct problem here, not only a leak.
- Deliberately falsifying or cherry-picking a benchmark result, including by
  quietly deleting the sentence that reported it.
- Repeatedly steering discussion to exhaust someone.

## Enforcement

Report to the maintainer by [private security advisory](https://github.com/aashish254/flash-coder/security/advisories/new)
subject line "conduct", or through GitHub's report button on the specific
comment. Reports are read, answered, and acted on as appropriate — warning,
removal of the content, temporary or permanent ban — with the outcome told to
both sides. If a report is about the maintainer, open a public issue asking for a
third party to read it and I'll step out of the decision.
